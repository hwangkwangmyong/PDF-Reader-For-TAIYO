# PDF図面情報抽出システム 設計書

## 1. 目的

本設計書は、PDF図面から `No.` と `☆` パーツ情報を抽出し、業務利用しやすい形式へ整形するための実装方針を定義する。

## 2. システム構成

- `app/page.tsx`
  - 画面エントリーポイント
- `components/DrawingExtractorClient.tsx`
  - ファイルアップロード、プレビュー、抽出結果テーブル表示
- `lib/pdfAnalysisEngine.ts`
  - PDF.jsによるページ解析、No./☆抽出、近傍判定
- `lib/formatDrawingItems.ts`
  - 抽出文字列正規化、数量抽出、結合結果生成
- `types/pdfAnalysis.ts`
  - 解析結果と整形結果の型定義

## 3. データモデル

### 3.1 ページ解析モデル

- `PageAnalysis`
  - `pageNumber`: ページ番号
  - `managementNo`: 右上No.（未検出時は `無`）
  - `managementNoBbox`: No.の表示位置（任意）
  - `extractedStarItems`: `StarTextHit[]`

- `StarTextHit`
  - `rawText`: ☆付き原文（または再構築した1項目）
  - `bbox`: 抽出位置
  - `quantityText`: 数量候補（任意）
  - `hasNearbyFactoryInstallNote`: `※工場取付` 近傍フラグ

### 3.2 整形出力モデル

- `FormattedDrawingItem`
  - `pageNumber`
  - `managementNo`
  - `normalizedText`: 画面表示用抽出文字列
  - `combinedText`: `No－抽出文字列(数量前まで)` の連結結果
  - `quantity`: 数値のみ
  - `hasNearbyFactoryInstallNote`

## 4. 抽出ロジック設計

### 4.1 No.抽出

1. ページ右上領域の文字トークンを収集
2. 正規表現で3桁番号を検索
3. ヒットなしの場合は `無`

### 4.2 ☆項目抽出

1. `☆` / `⭐` を含むトークンを抽出候補とする
2. 同一行トークンを `bbox` の縦重なり・Y差で判定して収集
3. 1トークン内に複数の `☆` がある場合は `☆` ごとに分割
4. 1項目は以下のいずれかで打ち切る
   - 数量単位検出（コ/枚 等）
   - `※` 記号検出
   - 次の `☆` 項目開始
5. 同一行抽出が短い場合は、右側トークンを使ったフォールバック再構築を実施

### 4.3 ※工場取付 近傍判定

1. `☆` 項目を基準点にする
2. `工場取付` を含むトークンを探索
3. 「☆より上方向」かつ横方向が近い場合のみ `true`

## 5. 整形ロジック設計

### 5.1 抽出文字列 (`normalizedText`)

- `☆` 以降を対象とする
- `※` 以降は除外
- 数量終端（`1コ`、`2枚` など）までを1項目とする

### 5.2 数量 (`quantity`)

- 対象例: `1コ`, `12枚`, `３コ`, `3ｺ`
- 正規化:
  - 全角数字 -> 半角数字
  - 半角 `ｺ` -> 全角 `コ`
- 保存値:
  - 単位を除いた数値のみ（例: `12枚` -> `12`）

### 5.3 結合結果 (`combinedText`)

- 形式: `<Noまたは無>－<抽出文字列(数量前まで)>`
- 除去対象:
  - 数量および以降文字列
  - `（本）` / `(本)`
  - `L=` / `L＝` と数値

## 6. 画面表示設計

### 6.1 プレビュー領域

- PDF画像を表示
- No.位置を青枠、☆位置を赤枠で表示
- テーブル行クリックで該当ページへスクロール

### 6.2 テーブル領域

2種類のリストを表示する。

1. 全抽出結果
2. `※工場取付` 近傍なし結果

列順は以下で統一する。

- `ページ`
- `No.`
- `抽出文字列`
- `結合結果`
- `数量`（数値のみ）

## 7. エラーハンドリング

- 非PDFアップロード時: エラーメッセージ表示
- 解析失敗時: エラーメッセージ表示と状態リセット
- No.未検出: `無` を表示
