# PDF図面情報抽出システム 要件定義書

## 1. システム概要

建築用PDF図面から、管理番号（No.）および「☆」付きパーツ情報を自動抽出し、バックオフィス業務に利用できる一覧データへ整形する。

## 2. 機能要件

### 2.1 PDFアップロード・解析基盤

- 対応フォーマット: PDFファイル限定
- ページ分割処理: 複数ページPDFをページ単位で解析し、ページ番号を保持
- プレビュー表示: PDF画像と抽出範囲（No./☆）を重ねて表示できる

### 2.2 OCR抽出・整形ロジック（コア機能）

- No.抽出:
  - 各ページ右上タイトルブロック付近から管理番号（例: `001`, `002`）を取得
  - 未検出時は `無` とする
- ☆マーク文字列抽出:
  - 図面内の `☆` / `⭐` を含む文字列を抽出対象とする
  - `☆PH1 ... 1コ`、`☆PH2 ... 2コ` のように、複数項目は項目ごとに分離する
  - `TH` のような星なし文字列は抽出対象外
- 数量抽出:
  - `1コ`, `12枚`, `３コ` などの数量を抽出する
  - 数量列は単位を除いた数値のみ保持・表示する（例: `1コ` -> `1`）
- 抽出文字列ルール:
  - `☆` 以降を対象とする
  - `※` 以降は不要として除外する
  - 数量単位（コ/枚 等）を終端として1項目を確定する
- 結合結果ルール:
  - `No.（または無）` と抽出文字列（数量より前）を `－`（全角ハイフン）で連結
  - 結合結果から以下は除去する:
    - 数量および数量以降の文字列
    - `（本）` / `(本)`
    - `L=` / `L＝` とその数値

### 2.3 リスト出力

- 抽出・整形結果をテーブル表示する
- 列は `ページ / No. / 抽出文字列 / 結合結果 / 数量` の順で表示する
- 各行は抽出元ページへジャンプできるメタデータを保持する
- 抽出・整形リストは2種類表示する:
  - 全抽出結果
  - `※工場取付` の近傍記載なし一覧

### 2.4 ※工場取付の近傍判定

- 判定基準は「☆抽出位置の上方向付近」に `※工場取付` があるかどうか
- 同一ページに存在するだけでは除外条件にしない

## 3. 技術スタック（現行）

- Frontend: Next.js 14+（App Router）
- Language: TypeScript
- OCR / PDF解析: PDF.js（必要に応じて Cloud Vision API 追加）
- Styling: Tailwind CSS

## 4. データ要件（型設計方針）

- ページ単位で解析結果を保持する
- No.はページ単位の必須値として扱い、未検出は `無`
- ☆付き文字列は抽出ヒット配列で保持する
- 整形出力レコードは以下を保持する:
  - ページ参照情報
  - 抽出文字列
  - 結合結果
  - 数量（数値のみ）
  - `※工場取付` 近傍判定フラグ
