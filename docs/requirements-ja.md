# PDF図面情報抽出システム 要件定義書

## 1. システム概要

建築用PDF図面から、管理番号（No.）および特定の記号（☆）を含むパーツ情報を自動抽出し、バックオフィス業務を効率化するデータ整形ツールを提供する。

## 2. 機能要件

### 2.1 PDFアップロード・解析基盤

- 対応フォーマット: PDFファイル限定
- ページ分割処理: 複数ページPDFをページ単位で解析し、ページ番号を保持
- プレビュー表示: PDF画面表示とOCR抽出範囲・結果の視認UI

### 2.2 OCR抽出・整形ロジック（コア機能）

- No.抽出:
  - 各ページ右上タイトルブロック付近から管理番号（例: `001`, `002`）を取得
- ☆マーク文字列抽出:
  - 図面内の「☆」を含むパーツ名や数量テキストを取得
- データ整形ルール:
  - 記号除去: 抽出文字列から `☆` を削除
  - 文字列結合: `右上のNo.` と `☆除去後文字列` を `－`（全角ハイフン）で連結
  - 出力例: `002－SP3 （本） 1枚 ※J1なし`

### 2.3 リスト出力

- 整形済みデータをテーブル形式で表示
- 各行は抽出元のページ情報（メタデータ）を保持し、参照可能にする

## 3. 技術スタック（想定）

- Frontend: Next.js 14+（App Router）
- Language: TypeScript
- OCR / PDF解析: PDF.js / Cloud Vision API
- Styling: Tailwind CSS

## 4. データ要件（型設計方針）

- PDFはページ単位で解析結果を保持する
- No.はページ単位の必須情報として扱う
- ☆付き文字列は配列で保持し、整形時に1件ずつ出力レコードを生成
- 出力レコードはUI表示とページ参照に必要な最小メタデータを保持する
